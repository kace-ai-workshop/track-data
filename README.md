# 📊 AI Workshop — Track Data & Analytics

Задание: сделать CLI-утилиту на Python, которая принимает CSV, анализирует структуру, генерирует SQL и загружает данные в SQLite.

Запуск:

```bash
python loader.py --input data.csv --db output.db
```

## Как работать

> [!WARNING]
> Код руками не пишем: работаем через Cursor-агента и итерации.

1. Use this template.
2. Клонировать репозиторий.
3. Заполнить `PROJECT.md`.
4. Заполнить `TASK.md`.
5. Давать задания по одному.
6. Проверять после каждого шага.
7. Итерировать до прохождения критериев.
8. Пушить и смотреть CI.
